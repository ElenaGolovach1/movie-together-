# Вдвоём — кино на двоих

Сайт, где двое смотрят одно видео синхронно (Play, Пауза, перемотка у обоих) и разговаривают голосом и в чате.
Работает в браузере на Android и iPhone, ничего устанавливать не нужно.

## Как это будет работать у вас
1. Вы открываете сайт → «Создать комнату» → «Пригласить» → отправляете ссылку девушке.
2. Она открывает ссылку на iPhone (лучше в Safari), вводит имя, нажимает «Войти».
3. Вы вставляете ссылку на видео → «Смотреть» → Play. Включаете микрофон — и вы вместе.

## Шаг 1. Запуск на своём компьютере (по желанию, для проверки)
1. Установите Node.js (nodejs.org, кнопка LTS).
2. Откройте папку проекта в терминале и выполните: `node server.js`
3. Откройте в браузере `http://localhost:3000`.
Так вы увидите сайт, но девушка по такой ссылке не зайдёт — для этого нужен шаг 2.

## Шаг 2. Выложить в интернет бесплатно (Render.com)
1. Зарегистрируйтесь на github.com, создайте репозиторий (New repository) и загрузите в него файлы проекта
   (кнопка «Add file → Upload files», перетащите всё содержимое папки, включая папку `public`).
2. Зарегистрируйтесь на render.com (можно через GitHub).
3. New → Web Service → выберите свой репозиторий.
4. Заполните: **Runtime** — Node, **Build Command** — оставьте пустым, **Start Command** — `node server.js`, **Instance Type** — Free.
5. Нажмите Create. Через пару минут появится адрес вида `https://название.onrender.com` — это ваш сайт, он уже с `https`
   (микрофон работает только с https).

Особенности бесплатного тарифа Render (по их документации): после 15 минут без активности сайт «засыпает», и первое открытие
занимает около минуты. Пока комната открыта, сайт не засыпает. Лимит — 750 часов в месяц, для двоих хватает.

## Какие ссылки на видео подходят
Нужна **прямая ссылка на видеофайл**: `.mp4`, `.webm` или поток `.m3u8` (HLS). Ссылка на страницу сайта с плеером не сработает —
браузер не может достать видео из чужой страницы. Платные сервисы (Netflix, Кинопоиск, YouTube и т. п.) не поддерживаются —
защиту (DRM) приложение не обходит. Для iPhone видео должно быть в формате mp4 (H.264); `.mkv` и `.avi` в Safari не играют.
Проверить, что всё работает, можно кнопкой «Попробовать тестовое видео».

## Советы
- Надевайте наушники: иначе звук фильма попадёт в микрофон и собеседник услышит эхо.
- На iPhone браузер может потребовать одно касание, чтобы разрешить автозапуск и звук — появится розовая кнопка, нажмите её.
- Если голос не соединяется (бывает при мобильном интернете у обоих), нужен TURN-сервер. Получите бесплатный на metered.ca
  и задайте в Render (Environment) переменные `TURN_URL`, `TURN_USER`, `TURN_PASS`.
- Автопроверка сервера: `node test.js`.

## Что где лежит
- `server.js` — сервер: комнаты, синхронизация, чат, передача сигналов для голоса.
- `public/index.html`, `public/style.css`, `public/app.js` — сайт.
- `test.js` — автотест.
